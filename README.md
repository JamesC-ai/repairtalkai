# RepairTalkAI

Private browser-local conflict wording reflection and repair-draft generator.

The production build includes 15 focused SEO pages, policy and support pages, a 19-URL sitemap, and IndexNow submission automation. Conversation text stays in the browser. The tool is not therapy, mediation, abuse diagnosis, legal advice, or a safety assessment.

## Commands

- `npm test`
- `npm run dev`
- `npm run deploy`
- `npm run indexnow`
